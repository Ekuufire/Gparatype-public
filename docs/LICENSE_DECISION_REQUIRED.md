# License decision required

This repository does **not** currently include a `LICENSE` file.

A human decision is required before any public GitHub (or other) release
regarding:

- open-source license choice (if any);
- institutional / ownership rights;
- redistribution terms for code, curated tables, and reference sequence
  redistributions (NCBI / GenBank terms of use remain separately binding).

**Do not invent a license or institutional ownership claim in automation.**

Until a license is chosen and committed as `LICENSE` (or equivalent),
treat redistribution rights as **undefined**.

Related freeze label: Gparatype **0.2.1-research** (`v0.2.1-research-freeze`).
